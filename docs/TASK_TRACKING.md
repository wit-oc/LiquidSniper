# Task tracking for LiquidSniper

We’re keeping Phase 1 work tracking **in-repo** to minimize tool sprawl.

## Canonical tracker

- `WORK_ITEMS.md` is the canonical board.

## How we use it

- Add new items to **[Later]**.
- Promote to **[Next]** during planning.
- Mark **[Now]** when work starts.
- When done, move to the bottom or add a “Done” section.

## Optional upgrade paths

If/when we want richer tracking:

1) **GitHub Issues + Projects**
- great for PR linkage, assignment, and kanban

2) **Notion tasks DB**
- already used elsewhere for Redact’s tasks

We can keep the repo board as the source of truth even if we mirror items into Notion.
